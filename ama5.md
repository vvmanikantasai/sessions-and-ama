# AMA5

### How to remove a cached file in Git?

Use:

```bash
git rm --cached <file-name>
```

This removes the file from Git tracking but keeps it in your local folder.

### What is an API key?

An API key is a unique token used to identify and authenticate an application when accessing an API.

### What is the use of `encodeURI()`?

`encodeURI()` converts special characters in a URL into a valid format so the URL can be safely transmitted.

### What is a call stack?

A call stack is a data structure that keeps track of function calls during program execution.

### Which is more expensive: Reflow or Repaint?

**Reflow** is more expensive because it recalculates the layout of elements, while repaint only updates the visual appearance.

### What is a stack trace?

A stack trace is a list of function calls that shows the execution path leading to an error.

### What is the default state of a Promise?

The default state of a Promise is **Pending**.

### Are REST APIs stateful or stateless?

REST APIs are **stateless**, meaning each request contains all the information needed to process it.

### What is the `extends` keyword in JavaScript?

The `extends` keyword is used to create a class that inherits properties and methods from another class.

### What is `Promise.any()`?

`Promise.any()` returns the first fulfilled promise from a group of promises and ignores rejected ones unless all fail.

### Difference between Authentication and Authorization

* **Authentication:** Verifies who the user is.
* **Authorization:** Determines what the user is allowed to access.

### What is Hosting (Deployment)?

Hosting is the process of deploying and making an application available on a server so users can access it over the internet.

### Why do websites load faster the second time?

Because the browser caches resources such as images, CSS, and JavaScript files locally, reducing download time.

### What is DNS?

DNS (Domain Name System) translates domain names into IP addresses that computers use to communicate.

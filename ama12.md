# AMA12

### Q: What is localeCompare() in JavaScript strings?
**A:** `localeCompare()` compares two strings based on language-specific alphabetical rules and returns `-1`, `0`, or `1`.

### Q: What is the difference between `==` and `===` in JavaScript?
**A:** `==` compares values after type conversion, while `===` compares both value and type without type conversion.

### Q: What is the Diffing Algorithm in React?
**A:** React's Diffing Algorithm compares the old Virtual DOM with the new Virtual DOM and updates only the changed parts of the real DOM.

### Q: What is Method Overriding?
**A:** Method overriding allows a child class to provide its own implementation of a method already defined in the parent class.

### Q: What is the use of `package.json`?
**A:** `package.json` stores project metadata, dependencies, scripts, and configuration required for a Node.js project.

### Q: What are the components of the Event Loop?
**A:** The Event Loop consists of the **Call Stack**, **Web APIs**, **Callback Queue (Task Queue)**, **Microtask Queue**, and the **Event Loop** itself, which moves tasks to the Call Stack when it's empty.

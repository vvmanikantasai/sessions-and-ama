# AMA11

### Q: How do you convert an integer to a string in JavaScript?
**A:** Use `String(num)`, `num.toString()`, or template literals like `` `${num}` ``.

### Q: Difference between Call Stack and Callback Queue?
**A:** The Call Stack executes function calls, while the Callback Queue stores asynchronous callbacks waiting to be executed.

### Q: What are the utility methods of Promises?
**A:** Common utility methods are `Promise.all()`, `Promise.allSettled()`, `Promise.race()`, and `Promise.any()`.

### Q: What is `setTimeout()`?
**A:** `setTimeout()` schedules a function to execute after a specified delay in milliseconds.

### Q: What is an Async Function?
**A:** An `async` function always returns a `Promise` and allows the use of `await` inside it.

### Q: What is Optional Chaining?
**A:** Optional chaining (`?.`) safely accesses nested properties without throwing an error if a property is `null` or `undefined`.

### Q: Difference between Primitive and Non-Primitive Data Types?
**A:** Primitive types store single immutable values, while non-primitive types (objects, arrays, functions) store collections or references.

### Q: Difference between `for...in` and `for...of`?
**A:** `for...in` iterates over object keys, while `for...of` iterates over iterable values like arrays and strings.

### Q: What is String Interpolation?
**A:** String interpolation inserts variables or expressions into strings using template literals (`` `${}` ``).

### Q: What is `unshift()`?
**A:** `unshift()` adds one or more elements to the beginning of an array and returns the new length.

### Q: What does `JSON.stringify()` do?
**A:** `JSON.stringify()` converts a JavaScript object or value into a JSON string.

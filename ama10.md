# AMA 10

### Q: What is a Messaging Queue?
**A:** A messaging queue is a system that stores messages and delivers them between producers and consumers asynchronously.

### Q: What does a Docker Compose file do?
**A:** A `docker-compose.yml` file defines and manages multiple Docker containers as a single application.

### Q: Difference between RabbitMQ and Result Backend?
**A:** RabbitMQ is a message broker that delivers tasks to workers, while a result backend stores the results of completed tasks.

### Q: What is an Exchange in RabbitMQ?
**A:** An exchange receives messages from producers and routes them to the appropriate queues based on routing rules.

### Q: Which protocol does RabbitMQ use?
**A:** RabbitMQ primarily uses the **AMQP (Advanced Message Queuing Protocol)**.

### Q: Difference between Docker and Kubernetes?
**A:** Docker is used to build and run containers, while Kubernetes manages and orchestrates multiple containers across servers.

### Q: How can we create a Docker image?
**A:** Create a `Dockerfile` and run the command `docker build -t image_name .`.

### Q: What are the types of Exchanges in RabbitMQ?
**A:** The main exchange types are **Direct**, **Fanout**, **Topic**, and **Headers**.

### Q: What is Sharding in MongoDB?
**A:** Sharding splits data across multiple servers to improve scalability and distribute load.

### Q: Why do we use Kafka?
**A:** Kafka is used to handle high-volume, real-time data streaming with high throughput and fault tolerance.

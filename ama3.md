# AMA 2

## 1. What is `position: relative`?

`position: relative` is used to move an element from its original position while still keeping its original space on the webpage.

---

## 2. What is `place-items` in flexbox?

`place-items` is mainly used in CSS Grid to align items horizontally and vertically and is not commonly used in flexbox.

---

## 3. What are `translateX()` and `translateY()` in CSS transform?

`translateX()` moves an element left or right, while `translateY()` moves it up or down.

---

## 4. What are lists in HTML?

Lists in HTML are used to organize items in an ordered or unordered way.

---

## 5. How many types of heading tags are there in HTML?

There are 6 heading tags in HTML, from `<h1>` to `<h6>`.

---

## 6. What is the use of the `data-*` attribute in HTML?

The `data-*` attribute is used to store custom information inside HTML elements.

---

## 7. What is the order of CSS specificity?

The order of CSS specificity is: element selector → class selector → ID selector → inline CSS → `!important`.

---

## 8. What is `order` in flexbox?

The `order` property is used to change the display order of flex items without changing the HTML structure.

---

## 9. Difference between `<link>` and `<a>` tag?

| `<link>`                                    | `<a>`                          |
| ------------------------------------------- | ------------------------------ |
| Used to connect external resources like CSS | Used to create clickable links |
| Written inside `<head>`                     | Written inside `<body>`        |

---

## 10. What is the default direction in flexbox?

The default direction in flexbox is `row`, meaning items appear from left to right.

---

## 11. What is the `placeholder` attribute?

The `placeholder` attribute shows hint text inside an input field.

---

## 12. Difference between `fixed` and `sticky`?

| `fixed`                       | `sticky`                                 |
| ----------------------------- | ---------------------------------------- |
| Always stays fixed on screen  | Becomes fixed after scrolling to a point |
| Does not move while scrolling | Moves until reaching a position          |

---

## 13. What is the purpose of `visibility: hidden`?

`visibility: hidden` hides an element but still keeps its space on the webpage.

---

## 14. What is an HTML page layout?

An HTML page layout is the structure used to organize sections of a webpage like header, content, and footer.

---

## 15. Why do we use metadata in HTML?

Metadata is used to provide webpage information to browsers and search engines.

#  AMA14

## Q1. What is encapsulation?
**Answer:** Encapsulation means keeping data and the methods that use that data together in one class. It also hides data from direct access.

## Q2. Explain fan-out exchange.
**Answer:** A fan-out exchange sends the same message to all queues connected to it. It ignores the routing key.

## Q3. How do you pass inline styling in React?
**Answer:** Use the `style` prop with a JavaScript object. Example: `style={{ color: "red", fontSize: "20px" }}`.

## Q4. What is the difference between `docker ps` and `docker ps -a`?
**Answer:** `docker ps` shows only running containers. `docker ps -a` shows all containers, including stopped ones.

## Q5. What is abstraction?
**Answer:** Abstraction means showing only the important details and hiding the internal implementation from the user.

## Q6. Explain deadlock.
**Answer:** A deadlock happens when two or more processes wait for each other forever, so none of them can continue.
